# 고객 문안과 관리자 검토 구분 보완

2026-11-07 (한국시간). 사용자 요청: 고객 문안은 자연스럽게 생성하고, 관리자는 사실·제공 주장·활용 가설을 구분해 확인한다.

- [x] 고객용 생성 지시와 관리자 전용 copy_review 분리.

- [x] 관리자 검토 메모와 기존 요약·광고 문구의 명시적 정리 버튼 추가.
- [x] 회귀·권한·공개 DTO·빌드 검증.

자동 변환은 지정한 구분표시에만 적용한다. 숫자·계약조건·확인사항·자료 인용 원문을 바꾸거나 검증 완료 상태로 승격하지 않는다. 승인된 공개 snapshot, 기존 사용자 편집, 기존 AI 분석은 자동 갱신하지 않는다. 기존 요약은 관리자가 정리 버튼을 누른 뒤 저장·승인한다.

## 구현과 사용 흐름

- 새 분석: 고객용 요약·제목·블로그·카드뉴스는 자연스러운 문장으로 생성하도록 지시하고, 관리자 분류는 별도 `copy_review`에 저장한다. '장기 임대'만 있는 자료를 '8년'으로 구체화하거나, 미확인 계약 승계를 확정하지 않도록 지시했다.
- AI가 기존 구분표시를 반환하면 출처·검토 문장으로 바꾸며, 원래 AI 문구는 `_copy_original`에 보관한다. 원자료 인용 후보 `document_facts`는 수정하지 않는다.
- 관리자는 광고 콘텐츠 패키지의 '관리자 문안 검토 메모'에서 제공정보/제공자 주장/활용가설/확인필요를 본다. 이는 AI의 분석 당시 분류이며 실제 검증 상태가 아니다. 이 메모와 원본 AI 문구는 고객 DTO에서 제외된다.
- 기존 초안은 '요약의 구분표시 정리' 또는 '선택 문구의 구분표시 정리'를 명시적으로 누른 뒤 검토·저장한다. 기존 고객 승인본은 재승인 전까지 유지된다.

## 검증 결과

- 통합 readiness 25항목 통과: Python 54개, Node 102개, 격리 SQL 3종 및 빌드/타입 검사 포함.
- 마지막 UI 버튼 추가 후 프런트 빌드, 관련 API/포맷터 회귀를 추가 확인했다.
- 실제 관리자·공개 handler를 사용하는 로컬 모의 브라우저 검증 5개 그룹 통과: 초기 초안 보존, 요약 정리/명시적 저장/승인본 보존, 광고 문구 정리/저장, 고객 미리보기의 비공개 메모 제외, 재조회 후 보존·반복 정리 방지. 375/768/1440 너비 및 런타임 오류/외부 요청 없음 확인.
- 합성 자료만 사용했다. 실제 AI 서비스 호출과 생성 품질·계약내용의 사실 검증은 수행하지 않았다. 문구 정리 자체가 원문의 사실성을 보장하지 않는다.
