# SpacePick 개발계획서 — 완료 항목과 남은 작업

기준일: **2026-11-07, 한국시간**

**v2.1 S0~S6 로컬 완료:** 고객 목적 선택, 유형별 핵심 조건, 근거·제약 판단 카드, 목적별 콘셉트·자료 표현, 확인 요청→문의/CRM, 제공자료 기반 1차 분석과 통합 검증을 완료했다. 개발 브랜치는 `feature/spacepick-v2-1`이며 운영 main에 병합하거나 배포하지 않았다. [완료 보고서](../SPACEPICK_V2_1_REPORT.md), [재개 상태](../SPACEPICK_V2_1_RUN_STATE.json), [작업 이력](../SPACEPICK_V2_1_PROGRESS.md)이 현재 기준이다.

이 문서는 현재 상태를 빠르게 확인하기 위한 계획서다. 상세 구현 이력은 [기존 개발계획·작업 기록](SPACEPICK_V2_PLAN.md)에 보관한다.

**최신 우선순위:** [관리자 웹 중심 전환 실행계획](../SPACEPICK_ADMIN_WEB_TRANSITION_PLAN.md)을 작성했다(T15/W0). 간단 입력·자료 등록, 확실한 저장/접수증, 전용 작업자, 웹 상태/실패 복구, 수동 AI 이미지 준비가 대상이다. W1~W9는 미착수이며 이번 요청에서는 계획·기록만 수정했다. 기존 Telegram 즉시 실행 복구를 주 개발 목표로 유지하지 않는다.

**시험 환경 선행 과제:** 개발 중 본인만 볼 수 있는 실제 배포 검증 환경을 연결한다. [본인 전용 배포 계획](../SPACEPICK_PRIVATE_PREVIEW_PLAN.md)의 P0~P6으로 관리한다. 기존 관리자 비공개 초안 미리보기는 있지만, 본인 전용 배포/테스트 데이터 분리는 아직 미완료다. 기존 호스팅·Supabase 관리 연결 확인이 다음 작업이다.

**추가 기능:** [등록 매물 다시 글작성](COPY_REWRITE.md)을 구현했다. 선택 문안/작성 방향 → 기존/새 글 비교 → 명시적 비공개 초안 적용·폐기 흐름이며, 실제 AI/운영 반영은 미완료다. 통합 검사는 재작성 회귀를 포함해 37항목(Python 65·Node 146·격리 SQL 7) 통과했다. 아래 v2.1 기준 35항목 기록과 구분한다.

**추가 이미지 기능:** [Gemini 웹용 프롬프트](IMAGE_PROMPTS.md)를 구현했다. 대표/콘셉트·생성/수정·표현 방향과 원본/권한을 반영하고 복사·파일 내려받기를 제공한다. 추가 AI/이미지 비용·DB 변경 없음. 최신 통합 검사는 38항목(Python 65·Node 152·SQL 7) 통과했고, 운영 프런트 반영·실제 Gemini 결과 확인은 남아 있다.

## 1. 현재 상태

**주요 기능의 코드 구현과 로컬 검증은 완료됐지만, 최신 관리자·고객 화면과 Supabase 변경의 운영 반영은 아직 완료되지 않았다. 상가·건물·토지 등을 대상으로 제공자료에 근거한 목적별 1차 검토를 구현했다. 외부 상권·시장 통계와 공식 규제 API 연동, 실제 자료 정확도 검증은 남아 있다.**

- **개발 완료**: 기능 코드와 로컬/합성 자료 검증이 끝난 상태. 운영 사이트 적용을 뜻하지 않는다.
- **운영 확인**: 실제 서비스의 해당 동작을 확인한 범위에만 사용한다.
- **반영 대기**: 코드가 준비됐으나 함수·DB·웹 호스팅 적용이나 운영 검증이 남은 상태.
- **미개발**: 계획에 있으나 실제 분석/기능 구현이 남은 상태.

v2.1 시작 기준 main은 `a35493c90447879d811a1b298b4fe83e8817a1d9`다. 이전 고객 문안·토큰 이름 호환 수정이 포함되어 있다. v2.1 소스는 별도 개발 브랜치에 저장하며 push SHA는 RUN_STATE/PROGRESS와 실제 원격을 대조한다.

기존 배포 승인은 유지한다. 기존 호스팅·Supabase·새 전용 worker의 실제 관리 권한과 적용 버전을 확인한 뒤 본인 전용 시험→운영 순서로 진행한다. GitHub 소스 업로드를 이 관리 연결이나 운영 적용의 증거로 간주하지 않으며, 이미 적용된 DB 변경을 무조건 다시 실행하지 않는다.

4번의 제공자료 기반 분석은 외부 유료 데이터 계약과 독립적으로 로컬 완료했다. 신규 개발의 다음 단위는 T15 W1/W2의 원문 보존·저장 복구/접수증·작업 계약이다. 운영 적용은 [v2.1 적용·복구 준비](../SPACEPICK_V2_1_DEPLOYMENT.md)와 새 전환 계획의 실행자 분리·시험/복구 순서를 함께 확인한다.

| 건물 전체 | 층별 용도·임차 구성·공실·임대차, 관리/설비 조건, 주변 수요와의 관계 | 임대 운영상 장점·제약과 확인사항. 개별 상가의 업종 추천과 구분 |
| 토지 | 지번·지목·용도지역·이용규제, 도로 접면/폭·진입 권리, 지형·경사, 전력·상하수도 등 기반시설 | 이용 방향별 입지 조건, 제약, 추가 조사·협의가 필요한 항목 |
| 공장·물류 | 도로망·대형차 진입·회전·상하차, 시설·설비·운영 및 임차 조건 | 운영 목적과 실제 시설 조건이 맞는지 검토할 근거 |

각 분석은 **분석 내용 → 사용한 근거와 기준일 → 의미·제약 → 추가 확인사항**으로 제시한다. 자료 없는 유동인구·매출·공실률·이동시간을 생성하지 않는다. 확인 목록이나 지도 링크만 표시한 상태를 분석 완료로 처리하지 않는다.

자료가 확보된 항목은 분석하고, 부족한 항목은 어떤 자료가 필요한지 표시한다. 개발·허가 가능성, 계약 승계, 수익을 확정하거나 보장하지 않는다.

## 6. 후속 확장으로 남아 있는 항목

- 광고 채널 예약·자동 발행: 현재 콘텐츠 작성·편집·내려받기와 별도 범위.
- 조회/문의 성과 대시보드: 수집·익명화·중복 제외·보관 조건과 집계 기능 필요.
- 건물 전체 고급 자산관리: 기본 목적·조건·부분 렌트롤은 구현했으나 자동 계약 수집·시장 비교·회계/세무·완전한 자산관리 기능은 별도 범위.

위 항목은 구현 완료 항목에 포함하지 않는다. 전체 우선순위는 운영 연결 복구와 고객 판단 정보·유형별 분석을 앞에 둔다.
