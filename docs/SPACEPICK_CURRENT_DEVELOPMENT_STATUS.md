## 1. 현재 상태

**주요 기능의 코드 구현과 로컬 검증은 완료됐지만, 최신 관리자·고객 화면과 Supabase 변경의 운영 반영은 아직 완료되지 않았다. 상가·건물 상권 분석과 토지 입지 분석은 미개발이다.**

- **개발 완료**: 기능 코드와 로컬/합성 자료 검증이 끝난 상태. 운영 사이트 적용을 뜻하지 않는다.
- **운영 확인**: 실제 서비스의 해당 동작을 확인한 범위에만 사용한다.
- **반영 대기**: 코드가 준비됐으나 함수·DB·웹 호스팅 적용이나 운영 검증이 남은 상태.
- **미개발**: 계획에 있으나 실제 분석/기능 구현이 남은 상태.

정리 기준 main은 `bc49605`이며, 최신 기능 코드 커밋은 `4b9c379`다. 토큰 이름 호환 수정 `246f549`도 포함한다. GitHub 소스 반영은 완료했다.

### 검증 범위

- 통합 검사 **25항목 통과**: Python 54개, Node 102개, 격리 SQL 3종, 빌드·타입 검사 포함.
- 문안 보완 브라우저 검증 **5개 그룹 통과**: 요약/광고 문구 정리, 명시적 저장, 기존 승인본 보존, 고객 화면의 비공개 메모 제외, 재조회 후 보존.
- 375/768/1440 화면 너비를 검증했다. 마지막 UI 수정 후 빌드와 관련 회귀도 확인했다.
- 토큰 별칭은 별도의 접수 API 검사 8개와 타입 검사를 통과했다.
- 합성 자료·모의 서버 검증을 실제 운영 통합 검증이나 실제 AI 결과의 사실 검증으로 표시하지 않는다.

배포는 이미 사용자에게 승인받았다. 현재 대기는 추가 승인 부족이 아니라 **기존 웹 호스팅 및 Supabase 함수/DB 배포를 실행할 관리 연결이 없는 상태**다. GitHub push 연결은 정상이다. 이미 적용된 DB 변경을 무조건 다시 실행하지 않는다.

운영 배포 연결을 기다리는 동안에는 4번의 제공자료 기반 분석 개발을 진행할 수 있다. 외부 유료 데이터 계약을 이 단계 전체의 차단 사유로 삼지 않는다.

## 5. 상가·건물·토지 분석의 구체적인 개발 범위

| 대상 | 다룰 내용 | 제공할 결과 |
| --- | --- | --- |
| 상가 | 배후 주거/업무 수요, 접근·동선·가시성·주차, 주변 업종·경쟁, 실제 임대/공실 자료 | 해당 업종을 검토할 근거, 입지 강점·약점, 추가 조사 항목 |
| 건물 전체 | 층별 용도·임차 구성·공실·임대차, 관리/설비 조건, 주변 수요와의 관계 | 임대 운영상 장점·제약과 확인사항. 개별 상가의 업종 추천과 구분 |
| 토지 | 지번·지목·용도지역·이용규제, 도로 접면/폭·진입 권리, 지형·경사, 전력·상하수도 등 기반시설 | 이용 방향별 입지 조건, 제약, 추가 조사·협의가 필요한 항목 |
| 공장·물류 | 도로망·대형차 진입·회전·상하차, 시설·설비·운영 및 임차 조건 | 운영 목적과 실제 시설 조건이 맞는지 검토할 근거 |

각 분석은 **분석 내용 → 사용한 근거와 기준일 → 의미·제약 → 추가 확인사항**으로 제시한다. 자료 없는 유동인구·매출·공실률·이동시간을 생성하지 않는다. 확인 목록이나 지도 링크만 표시한 상태를 분석 완료로 처리하지 않는다.

자료가 확보된 항목은 분석하고, 부족한 항목은 어떤 자료가 필요한지 표시한다. 개발·허가 가능성, 계약 승계, 수익을 확정하거나 보장하지 않는다.

## 6. 후속 확장으로 남아 있는 항목

- 광고 채널 예약·자동 발행: 현재 콘텐츠 작성·편집·내려받기와 별도 범위.
- 조회/문의 성과 대시보드: 수집·익명화·중복 제외·보관 조건과 집계 기능 필요.
- 수익형 건물 독립 화면: 기존 `income` 유형 호환은 유지하지만 전체 건물 전용 모듈 범위·화면은 추가 확정 필요.

위 항목은 구현 완료 항목에 포함하지 않는다. 전체 우선순위는 운영 연결 복구와 고객 판단 정보·유형별 분석을 앞에 둔다.
