# Gemini 웹용 이미지 생성·수정 프롬프트

2026-11-07 한국시간. 로컬 구현·검증 결과와 운영 반영 상태를 구분한다. 이 기능은 매물 검토실에서 Gemini 웹에 붙여넣을 요청문을 준비한다.

## 사용법

1. 등록 매물의 초안을 열고 **AI 이미지 표현 방식 → Gemini 웹용 이미지 프롬프트**로 이동한다.
2. 대표 이미지 또는 활용 콘셉트를 고르고 **새 이미지 생성 / 기존 AI 이미지 수정**을 선택한다.
3. “구조와 도로를 유지하고 외벽 색감만 회색으로” 같은 원하는 변경을 입력한다.
4. 사진·도면 방식은 참고할 실제 자료와 사용 권한을 먼저 선택한다. 수정 작업은 기존 AI 이미지도 Gemini에 함께 첨부한다. 첨부할 자료 목록이 패널과 프롬프트에 표시된다.
5. **이미지 프롬프트 복사** 또는 **이미지 프롬프트 내려받기**로 문안을 가져간다. 다운로드는 UTF-8 텍스트다. Gemini 웹에서 안내된 원본을 첨부하고 사용한다.

프롬프트는 현재 편집 화면을 반영하며, 작성 방향은 이 패널에서 임시 편집한다. 문안 구성·복사·다운로드는 초안 저장, 이미지 생성 요청, 예산 사용 또는 게시를 수행하지 않는다. 실제 이미지 생성·검수/교체는 기존 작업과 구분한다.

## 구성 규칙

- `supabase/functions/_shared/image-prompts.ts`의 순수 함수가 현재 관리자 데이터를 사용해 결정적으로 구성한다. 추가 모델 호출·서버 endpoint·DB migration·worker/예산 설정 변경이 없다.
- 기존 `imageSettings`의 개념/도면/사진 방식과 선택한 실제 자료의 종류·매물 소속·AI 원본 제외·사용 권한을 확인한다. 자료·권한이 부족하면 프롬프트를 비우고 복사/다운로드를 차단한다. 실제 파일 바이트는 읽거나 내려받지 않는다.
- 기존 API 이미지의 16:9/단일 이미지/문자·번호·로고/콜라주 제외, 구역 중심 좌표(27,28)/(73,28)/(27,62)/(73,62)/(50,84), 미확인 조건·원본 보존 원칙을 웹용 문장에도 반영했다. API의 기존 생성 함수·유료 호출 자체를 변경하지 않았다.
- 구조화 프로필은 `visibleField` 공개 규칙을 재사용하고 제공/검증 상태만 포함한다. 비공개 값·생성 가설값·사용 권한/파생 공개 권한이 없는 값은 제외한다. 기본형 기존 fact는 비공개/미확인/AI 가설을 제외한다.
- 0과 누락을 구분한다. 수치·단위는 바꾸지 않으며 실제 용량 적합성·측량·허가로 승격하지 않는다. 공개할 수 있는 제공 조건이 없으면 추가 수치를 생성하지 않도록 명시한다.
- 연락처·정확한 주소·기존 요약/제목·sourceText·원본 경로/URL·파일/구역 ID·권한 메타데이터는 복사 문안에 포함하지 않는다. 콘셉트 이름/구역명은 활용 가설로 표시한다.
- 공장/물류/상가/토지/건물 전체의 검토 질문을 구분한다. 기존 industrial만으로 공장/물류를 확정하지 않는다.
- 사진 시점·구조·창문·출입구·도로 경계, 도면의 확인 가능한 벽·기둥·공간 관계를 유지하도록 요청한다. 수정 요청이 원본 보존과 충돌하면 원본을 우선한다. 프롬프트만으로 구조 정확성을 보장하지 않으며 사람이 실제 결과를 대조한다.

## 검증과 운영 적용

- 신규 `node supabase/tests/image-prompts.test.ts` 6개 통과: 5유형, 0/누락/비공개, 원본 자료·소속·권한, 사진/도면, 콘셉트/구역, 방향 길이/수정 제약, 기존 데이터 불변.
- 전체 `PGLITE_MODULE=/workspace/spacepick-test-tools/node_modules/@electric-sql/pglite/dist/index.js python scripts/check_v2_readiness.py` **38항목 통과**: Python 65, Node 152, 격리 SQL 7, 빌드/Edge 타입. 콘솔 `/tmp/image-prompts-readiness.log`, 상세 `showroom-web/test-results/v2-readiness.json`.
- 개발 브라우저: `IMAGE_PROMPT_QA=1 NODE_PATH=/opt/codex/runtimes/codex-primary-runtime/dependencies/node/node_modules CHROME_PATH=/usr/bin/chromium node showroom-web/scripts/property-facts-qa.cjs` 4그룹 통과. 실제 clipboard 읽기/쓰기·UTF-8 파일 다운로드와 문안 일치, 소속/권한, 375/768/1440px, 저장본/승인본 불변 확인.
- 최종 Worker 4그룹도 통과했다. showroom-web에서 `SPACEPICK_QA_PORT=5182 node scripts/serve-built.mjs`로 실행한다. 동일 검사에 `SHOWROOM_QA_URL=http://127.0.0.1:5182`를 추가해 빌드 결과와 API 요청 목록도 확인했다. 허용한 최초 초안 열기 외 저장·생성/예산 RPC 요청이 없는지 검사한다. 캡처/결과는 `test-results/image-prompts-built/`에 보존한다.
- 기존 관리자 전체 흐름도 `V21_ADMIN_QA=1`로 6그룹 통과했다. 이번 브라우저 검증 합계는 개발4+빌드4+관리자6=14그룹이다. 실제 AI·외부 Gemini 웹·운영 DB/사이트는 호출하거나 변경하지 않았다.
- 기능 자체는 기존 관리자 프런트에 포함된다. 전체 개발 브랜치를 운영에 반영할 때는 기존 v2.1/재작성 기능의 서버·SQL·설정 선행 조건을 각 배포 문서대로 확인한다. 이 기능 때문에 별도 DB 권한이나 AI 비용 한도를 늘리지 않는다.

운영 프런트 배포 및 실제 Gemini 웹 생성 결과의 품질·구조 보존 검증은 별도 미완료다. GitHub 개발 브랜치 업로드를 사이트 게시 완료로 표시하지 않는다.
