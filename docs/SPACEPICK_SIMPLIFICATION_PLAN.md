## 1. 방향

> **SpacePick = 매물 하나를 입력하면 "매물 한 장 페이지 + 채널별 홍보글 + 문의 알림"을 바로 만들어 주는 도구.**

판단 기준은 하나다. **이 페이지를 본 사람이 연락하고 싶어지는가?** 이 질문에 도움이 안 되는 기능은 만들지 않는다.

### 왜 바꾸나

- 지난 계획은 "관리자가 실수 없이 안전하게 게시하는 시스템"을 목표로 해서 복잡해졌다. 기획서 승인, 3단계 흐름, AI 대기열, 이미지 예산, 카드뉴스, 공공데이터 파이프라인이 그렇다.
- AI 작업자가 몇 시간에 한 번만 돌아서, 몇 분이면 될 수정이 몇 시간 걸린다.
- 실제 매매제안서 2건을 손으로 만들어 보니 필요한 것은 단순했다. 사실을 정리한 표, 핵심 숫자 강조, 쓰임새 제안, 계산, 사진, 연락처.
- 다른 AI와의 대화에서 나온 "홍보글 → 매물 페이지 → 문의" 구조가 사용자가 처음부터 원하던 모습이었다(2026-11-14 사용자 확인).

## 2. 제품 정의

### 입력 (10개 안팎)

| 항목 | 예 |
| --- | --- |
| 매물 기본 | 주소, 층, 전용면적, 서비스 면적(테라스 등) |
| 거래 조건 | 매매가 또는 보증금·월세·관리비, 「협의」 가능 |
| 현재 상태 | 공실 / 영업 중(업종, 계약 만료일), 시설 인수 가능 여부 |
| 확실한 설비 | 층고, 전력, 가스, 상하수도, 주차 — 아는 것만 |
| 특징 메모 | 소유자·중개사가 아는 사실 몇 줄 |
| 사진 | 실제 사진 여러 장 |
| **누구에게 팔고 싶은가** | 예: 카페·필라테스 창업자 / 임대수익 투자자 / 공장을 직접 쓸 기업 |
| 연락 방법 | 전화·문자·당근 채팅 등 |

### 출력

1. **매물 한 장 페이지** (`spacepick.kr/<주소이름>`): 실제 사진, 핵심 숫자, 쓰임새 제안, 계산기, 위치, 문의 양식. 휴대폰 우선.
2. **채널별 홍보글**: 당근마켓, 네이버 블로그, 카카오톡 공유 문구. 모두 매물 페이지 링크로 이어진다.
3. **문의 알림**: 페이지에서 문의가 오면 텔레그램(또는 문자)으로 바로 알린다.
4. **PDF** (C단계): 같은 내용을 A4 1장 요약 또는 여러 쪽 제안서로. 의뢰인 로고·연락처를 넣는다.

### 원칙 — 정직한 광고

- 숫자는 입력한 사실이나 공공데이터에서 온 것만 쓴다. AI가 숫자를 만들지 않는다.
- 계산기는 가정을 화면에 드러내고, 보는 사람이 직접 바꿀 수 있게 한다. "확정·보장" 표현은 쓰지 않는다.
- 사진은 실제 사진만 쓴다. AI 구상 이미지는 「AI 예상 이미지」로 표시하고 선택 사항으로 둔다.
- 거래 조건은 공개하거나 「협의」라고 솔직하게 쓴다. 연락처를 남겨야 조건을 알려 주는 방식은 쓰지 않는다.
- 주소와 금액 같은 핵심 정보는 눈에 띄게(붉은 굵은 글씨 등) 보여 준다.

### 만드는 흐름

```
입력(10칸 + 사진 + 누구에게) → [AI 몇 초] 페이지 문구·홍보글 초안 → 화면에서 바로 고치기 → 「올리기」
```

승인 단계와 대기열은 없다. AI 생성은 요청 즉시 처리한다.

## 3. 대상별 양식

| 양식 | 보는 사람 | 강조할 것 | 계산기 |
| --- | --- | --- | --- |
| 창업자용 (상가 임대) | 카페·학원·필라테스 창업자 | 면적·서비스 면적, 설비, 업종별 쓰임새, 초기 비용(권리금·시설 인수) | 좌석·테라스 매출 |
| 투자자용 (수익형 매매) | 임대수익을 사려는 사람 | 임차인, 보증금·월세, 계약 기간 | 수익률(보증금·월세·대출 금리) |
| 실사용 매수자용 (공장·물류) | 직접 쓸 기업 | 개요 표, 층고·전력·용도지역, IC 거리, 확장안 | 평당가, 확장 후 단가 |

첫 양식은 창업자용이다(A·B단계). 나머지 둘은 C단계에서 만든다.

## 4. 고객과 사업 순서

1. **사장님 상가(테라스 상가 201호)**: 첫 매물이자 첫 검증. 페이지와 홍보글을 2~4주 올려 조회와 문의가 실제로 오는지 본다.
2. **다른 건물주(임대인)**: 효과가 확인되면 "공실 홍보 페이지 제작"을 부업으로 판다. 건당 제작비 또는 작은 월 요금. 프리랜서 플랫폼, 지역 광고로 고객을 모은다.
3. **B2B 제안서(PDF)**: 지인 물류 컨설턴트 같은 의뢰인에게 같은 도구로 PDF 제안서를 만든다. 조건(건당 금액)을 미리 정하고, 아니면 호의로 돕는 일로 본다.
4. **공인중개사용**: 검증 이후에 판단한다. 법정 표시사항, 사무소별 계정 분리가 필요해 일이 많다.

수익은 **제작비·구독료**로 받는다. 거래 성사 보수(성공보수)는 중개 자격 문제가 있어 받지 않는다.

## 6. 단계별 작업

### A단계 — 201호 페이지 직접 만들기 (가장 먼저)

새 기능을 만들기 전에, 사장님 상가 하나를 손으로 완성해 결과를 본다.

- [ ] 사장님에게 사실 정보와 실제 사진을 받는다(2장 입력 항목).
- [ ] 창업자용 한 장 페이지를 만든다. 실제 사진, 핵심 숫자, 테라스 활용 계산기, 위치, 문의 양식.
- [ ] 문의 양식을 기존 문의 접수와 텔레그램 알림에 연결한다.
- [ ] 당근마켓·네이버 블로그 홍보글을 만든다.
- [ ] 사장님 확인 후 spacepick.kr에 올리고 홍보글을 게시한다.
- [ ] 2~4주 동안 조회 수와 문의 수를 기록한다.

완료 기준: 페이지가 운영에 올라가고, 문의 1건이 실제로 텔레그램 알림까지 도착한다.

### B단계 — 단순 입력과 즉시 생성 (창업자용)

A단계에서 손으로 한 일을 도구로 만든다.

- [ ] 관리자에 「간단 등록」 화면을 만든다. 2장 입력 항목 + 사진 + "누구에게".
- [ ] AI가 페이지 문구와 홍보글을 요청 즉시(수 초) 만든다. 대기열과 작업자를 거치지 않는다.
- [ ] 미리보기 화면에서 문장과 숫자를 바로 고치고 「올리기」로 공개한다.
- [ ] 기존 복잡한 흐름은 「고급」으로 숨긴다.

완료 기준: 새 매물 하나를 입력부터 공개까지 15분 안에 끝낸다. AI 대기 시간 1분 이내.

### C단계 — 양식 추가와 PDF

- [ ] 투자자용·실사용 매수자용 양식과 계산기(수익률, 평당가, 확장 후 단가)를 만든다.
- [ ] 숫자 자동 계산·대조(평당가, 수익률, 면적 합계)를 넣고 안 맞으면 경고한다.
- [ ] 같은 내용을 A4 PDF(1장 요약, 여러 쪽 제안서)로 출력한다.
- [ ] 의뢰인 로고·연락처 설정을 만든다.

완료 기준: 2026-11-13에 손으로 만든 제안서 2건과 같은 결과를 도구로 만든다.

### D단계 — 검증 결과에 따른 확장 (조건부)

A단계 결과를 보고 고른다.

- 다른 건물주에게 판매: 제작 주문 받는 방법, 요금.
- 공인중개사용: 광고 법정 표시사항 자동 삽입, 사무소별 계정.
- 숨겨 둔 기존 기능의 코드·데이터 정리.
